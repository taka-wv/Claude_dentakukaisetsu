# 電卓アプリ（C# / Windows フォーム）

C# と Windows フォームで作った、シンプルな電卓アプリです。

## できること

- 四則演算（＋ − × ÷）を続けて入力できる（例：`3+4×2=`）
- 計算は押した順に左から行う（×÷を先に計算しない）
- 小数点、マイナスの数（例：`3×-2`）の入力
- 1つの数は最大8桁。答えも8桁に収まるように四捨五入
- 0で割ったとき・桁があふれたときはエラー表示
- ［C］で1文字消す、［CA］ですべてクリア

## 動かし方

1. Visual Studio でソリューション（`.sln`）を開く
2. ［開始］ボタン（または F5 キー）で実行

※ Windows が必要です。

## 主なファイル

| ファイル | 内容 |
| --- | --- |
| `Form1.cs` | ボタンを押したときの処理と計算のロジック |
| `Form1.Designer.cs` | ボタンや表示欄の配置（Visual Studio が自動で作成） |
